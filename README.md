# Aura Perfumes

متجر أورا للعطور الفاخرة - منصة تسوق إلكترونية متكاملة.

## الميزات
- واجهة مستخدم مظلمة فاخرة (Luxury Dark Theme)
- لوحة تحكم متكاملة للإدارة والمستخدمين
- نظام سلة مشتريات 
- دعم للعملة السعودية واليمنية
- عرض تفاعلي وتجاوبي مع جميع الأجهزة

## التقنيات المستخدمة
- React & Vite
- Tailwind CSS & Tailwind Animate
- TanStack Router
- Lucide React (Icons)
